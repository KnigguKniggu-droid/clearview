# Project context

ClearView is a local-first browser inspector for visible financial disclosures, selected add-ons, and selected accessibility problems.

Stack: TypeScript strict mode, npm workspaces, framework-free DOM analyzer, React 19, Vite 6, Tailwind 3, Vitest 2, JSDOM 25, Chrome Manifest V3.

Current phase: implementation and regression tests.

Constraints: no paid LLM APIs, no third-party scraping endpoint, no collected patient or billing data, reversible local DOM changes, sample portals labeled as simulations.

Done: verified analyzer, three working portals, extension build, ZIP artifacts, honest setup/submission documentation, and reviewed demo video. External publication remains a separate approval step.

===== IBM Plex Sans and IBM Plex Mono =====

IBM Plex Sans and IBM Plex Mono by IBM Corp.
Source: Google Fonts (official font distributions)
Sans: https://github.com/google/fonts/tree/main/ofl/ibmplexsans
Mono: https://github.com/google/fonts/tree/main/ofl/ibmplexmono
Official family pages:
https://fonts.google.com/specimen/IBM+Plex+Sans
https://fonts.google.com/specimen/IBM+Plex+Mono

The Latin WOFF2 files are self-hosted in both ClearView applications.
IBM Plex Sans uses the variable IBMPlexSans-400.woff2 file for weights 400-700.
IBM Plex Mono uses IBMPlexMono-400.woff2, IBMPlexMono-500.woff2, and IBMPlexMono-600.woff2.
The supplied font software is unchanged. Local filenames identify the selected family/weight.
No Google Fonts request is made at application runtime.

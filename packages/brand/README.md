# ClearView — Open View

The original Open View mark pairs an open C with an independent source square. The mark identifies ClearView; it does not certify a page or its financial terms. The agent selected this direction under the user's delegated build instruction. It is not recorded as user-approved.

Three original concepts were compared in black. Choice Fold resembled a download arrow at small sizes. Paired Views resembled code brackets. Open View kept the strongest consumer-facing letterform. Its round source point was enlarged to a pixel-aligned square after the first 16px review.

Use `ClearViewBrand` for the shared Manrope wordmark and symbol. `tone="dark"` uses white/lime on navy; `tone="light"` uses navy/cobalt on light surfaces. Use `ClearViewMark` only where visible ClearView text already supplies the accessible name. SVGs in `assets/` contain geometry only. The runtime wordmark is text in the existing self-hosted, OFL-licensed Manrope font.

- Minimum symbol size: 16px. Use the supplied icon artwork for browser tabs and the extension toolbar.
- Clear space: at least the source square width (one eighth of the 256-unit canvas).
- Preserve the opening, the independent square, and the original proportions. Do not add shadows, gradients, outlines, or certification badges to the mark.
- Colors: navy `#13283e`, cobalt `#245dce`, lime `#c7ef72`, white `#ffffff`.

The extension includes PNG icons at 16, 32, 48, and 128px. Its permissions are unchanged. The web favicon uses the same icon SVG. Black and reversed masters are included. This is a product identity implementation, not a complete print identity kit.
